# Chrome Store Draft

## Name

Recall

## Short Description

一键收藏网页资料到飞书多维表格，自动整理核心内容和网页截图。

## Detailed Description

Recall helps you save useful web pages into your own Feishu Base with one click.

When you find a useful article, video, product page, paper, or reference, click the Recall extension icon. Recall captures the page title, URL, visible screenshot, source, tags, and a concise core-content summary, then saves them into your Feishu Base for later reading.

Main features:

- One-click capture from Chrome.
- Save page title, URL, screenshot, source, tags, and reminder time.
- Generate a Chinese core-content reading note from page content.
- Store records in the user's own Feishu Base.
- Mark items as unread or read in the table.

Recall is designed for lightweight personal knowledge capture, not heavy bookmarking.

## Privacy Summary

Recall processes the current page title, URL, visible screenshot, selected text, and visible page text only when the user clicks the extension to save the page. The public version stores data in the user's own Feishu workspace after Feishu authorization.

Recall does not sell user data.

## Reviewer Test Instructions

1. Install the extension.
2. Open the options page and connect a Feishu test account.
3. Open any public webpage.
4. Click the Recall extension icon.
5. Confirm that a new record is created in the connected Feishu Base.
6. Confirm that the record includes title, screenshot, core content, URL, tags, status, reminder time, saved time, source, and priority.
